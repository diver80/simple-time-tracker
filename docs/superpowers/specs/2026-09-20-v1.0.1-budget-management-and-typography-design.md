# Design Specification: Simple Time Tracker v1.0.1

**Date**: 2026-09-20  
**Status**: Approved  
**Version Target**: `1.0.1`  
**Application**: Simple Time Tracker (`stt`)  

---

## 1. Overview & Objectives

Simple Time Tracker v1.0.1 addresses two user experience priorities identified in v1.0.0:
1. **Full Budget & Project Lifecycle Management**: Enable deleting sample or completed projects, adding real client projects/budgets via a modal editor, and offering a one-click demo data purge. Ensure the default `--demo` flag is `false` so deleted records never respawn on restart.
2. **Tab Bar Typography & Glyph Fix**: Replace multi-byte emoji prefixes in the navigation bar that caused "tofu" boxes (missing glyph rectangles) in `gogpu/ui` font rendering on macOS.

---

## 2. Database & Data Layer

### 2.1 Repository Enhancements (`pkg/db/repository.go`)
* `DeleteProject(id int64) error`:
  * Sets `project_id = NULL` on any existing time entries referencing this project so past booking records and durations remain safe and uncorrupted.
  * Deletes the target project from `projects`.
* `DeleteCustomer(id int64) error`:
  * Deletes a customer from `customers`. Cascades or verifies no orphaned projects remain.
* `ClearAllDemoData() error`:
  * Deletes demo customers (`Acme Corporation`, `Starlight Media`), their associated projects, and any residual demo time entries.
* `CreateCustomerIfNotExists(name string) (*Customer, error)`:
  * Looks up customer by name; creates if not present.

### 2.2 Startup Configuration (`cmd/time-tracker/main.go`)
* Change default command-line flag `demoFlag := flag.Bool("demo", false, "Auto-seed demo clients and projects if database is empty")`.
* Version string bumped to `1.0.1`.

---

## 3. UI & Interactivity

### 3.1 Budgets Tab (`pkg/ui/project_view.go`)
* **Header Actions**:
  * `+ Projekt`: Opens `ProjectEditor` modal.
  * `Demodaten leeren`: Visible when sample projects are present, clears all demo records in one click.
* **Card Delete**:
  * Each project card displays a `✕` delete button at the top-right.
  * Clicking displays a confirmation inline (`Wirklich löschen? [Ja] [Nein]`).
  * On confirmation, invokes `repo.DeleteProject(p.ID)` and refreshes the list immediately.
* **`ProjectEditor` Modal (`pkg/ui/project_editor.go`)**:
  * Form fields:
    * `Kundenname` (`TextInput`)
    * `Projektname` (`TextInput`, required)
    * `Stundensatz` (`TextInput`, numeric float)
    * `Budgetstunden` (`TextInput`, numeric float)
  * Actions: `[💾 Speichern]` (validates input, creates customer if needed, creates project via `repo.CreateProject`, refreshes view) and `[✕ Abbrechen]`.

### 3.2 Typography & Tab Bar Polish (`pkg/ui/app_view.go`)
* Remove emojis from button labels to eliminate missing glyph boxes on macOS Cocoa:
  * `tabTrackerBtn`: Label `"Tracker"` (or `"00:00:00"` when timer is running).
  * `tabCalendarBtn`: Label `"Tag"`.
  * `tabExportBtn`: Label `"Export"`.
  * `tabProjectsBtn`: Label `"Budgets"`.
  * `tabShieldBtn`: Label `"Schutz"`.
